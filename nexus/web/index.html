NEXUS
Claude Code · Mission Control

Sigue en un solo lugar todo lo que Claude Code hace en tus proyectos: sesiones en vivo, tareas, tandas de trabajo y planes. Elige de dónde leer los datos.

Servidor local

La opción completa: tiempo real, historial que sobrevive a la limpieza de Claude Code y avisos. Ejecuta en una terminal:

node nexus/server.mjs --open

Carpeta ~/.claude

Sin instalar nada (Chrome o Edge). Elige la carpeta .claude de tu usuario. En macOS pulsa ⌘⇧. para ver carpetas ocultas.

Demo

Datos de ejemplo que se mueven solos: proyectos de desarrollo y episodios de un canal de YouTube.
